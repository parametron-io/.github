# Support

Parametron is an early-stage project.

For help with a public component:

- read the repository README and documentation first
- search existing issues and pull requests
- use GitHub Discussions when the repository has Discussions enabled
- use the closest issue form for reproducible bugs or concrete feature requests

Please keep questions and reports in the repository that owns the affected behavior.

Commercial support or service-level commitments are not implied by public repository participation.

For security vulnerabilities, do not use public support channels. Follow [SECURITY.md](SECURITY.md).
